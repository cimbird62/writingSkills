# 人物塑造：从“符号”到“人”

将角色的身份或性格标签发展成有来历、有矛盾、会作出选择的人。让观众从动作、关系和情境中理解人物，形成可记住的行为细节。

方法来自用户提供的 18 页人物塑造课件。课程页码、原案例与方法边界见 [课程参考](reference.md)。本技能针对故事人物与场景表达；角色外观定妆或纯画面构图不属于它的主要任务。

## 先确认任务

识别用户正在要求人物小传、角色诊断、场景改写、情绪设计，还是短片脚本。交付用户所需的那一种，不把每次人物任务都扩展成完整剧本。

保留用户给定的人物身份、关系、时代、经历、动作、情节结果与风格。已有材料足够时直接工作；缺失信息影响关键动机或关系时，提出最少的必要问题。可以推进的草稿，将补充设定标为建议。

区分三种信息：用户确定的事实、文本可以支持的推断、尚未确定的悬念。课件示例和练习是参考材料；不把案例剧情、15 秒时长或课堂作业要求自动套到其他任务。

## 核心：细节、反差、留白

- **细节让情绪可见。** 找到一个在具体压力下发生的小动作、道具变化或生活程序，让人物继续做事时露出内心。细节要影响观众对人物的判断，避免堆叠无关习惯。
- **反差形成张力。** 让外在状态、言语与行动、公众形象与私下选择产生有动机的差异。反差需要经历、关系或欲望支撑。
- **留白邀请参与。** 提供足够的可见线索，让观众推测人物知道什么、忍住什么或想做什么。保留解释空间，同时让动作和事件本身清楚。

对悲伤场景，选择人物正在努力维持的东西及其代价，使观众担心其处境和下一步。对喜剧场景，可以利用姿态、目标与结果的错位，但要让人物的行动逻辑成立。情绪强度服从用户方向。

## 八项人物技巧

按角色实际问题选择技巧；八项是诊断工具，不要求每次输出逐项填写。

| 技巧 | 落实方式 | 判断标准 |
|---|---|---|
| 1. 人物小传：筑牢根基 | 用“童年 → 青年 → 关键转折 → 当下状态”梳理重要经历；说明经历如何形成信念和选择 | 小传能解释当前行为，不只是生平清单 |
| 2. 差异展示：行动表达 | 将性格判断变成特定情境中的行为、节奏与回应 | 读者看到动作后能自己理解特征 |
| 3. 成长空间：留下裂缝 | 找到遗憾、执念、恐惧或弱点，明确它保护人物什么、又让其失去什么 | 裂缝会影响选择；用户未要求成长时不强加疗愈结局 |
| 4. 合理反差：打破标签 | 写清外在印象、实际选择与中间的因果联系 | 反差属于这个人物，能在压力下被验证 |
| 5. 多视角描写 | 根据关系差异，呈现不同配角如何看待同一人物 | 配角有自己的经验与利益，各视角能产生新信息 |
| 6. 三观定底色 | 说明人物相信什么、怎样判断对错、怎样排序重要事物，再用冲突挑战它 | 选择暴露价值底线；若写人物弧线，变化有代价和过程 |
| 7. 去脸谱化 | 从职业、习惯、处境与关系中形成独特行为特征 | 独特性超出“好妈妈”“霸总”“反派”等通用称呼 |
| 8. 重复展示 | 让关键行为在不同压力或关系中再次出现，视需要改变其结果 | 重复加深或修正印象，不机械重复同一段描写 |

小传中的因果可以写成：`重要经历 → 对世界的判断 → 自我保护方式 → 当下选择 → 付出的代价`。只补充当前任务需要的经历，不为角色编造完整人生档案。

## 将标签改成场景

从用户材料中找出人物此刻想完成的事、面临的阻碍、想掩饰的东西和不愿失去的东西。围绕这些信息构造可表演的行动。

例如“急躁”可以落在别人还没说完就打断、提前伸手去拿结果、连续按下无效按键等动作中；具体选择应符合人物职业、关系和场景条件。

写细节时依次考虑：触发它的具体信息；人物正在做的事；瞬间的节奏变化；人物如何继续、掩饰或改变行动。对白和动作可以保持不同的情绪表层，避免再加旁白解释已经可见的含义。

修订已有场景时，先找出最有用的细节与悬念，再减少重复解释。保留原文中的关键事实与剧情结果。

## 让人物在事件中选择

当用户要求情节或人物弧线时，将外部阻碍与人物的裂缝、目标或价值冲突相连。

- 建立一个具体目标和初始阻碍。
- 根据篇幅与调性，让人物尝试解决；新的困难应由已有条件、人物选择或明确出现的信息产生。
- 需要反转时，在前文留下可回看成立的线索，使新的结果暴露人物或关系的另一面。

课程的“冲突 → 升级 → 反转”适合其短片练习。安静的人物片段可以停在一次选择或一个动作上；不要为了反转改变用户给定的结局。

## 母亲、父亲等熟悉角色

先找其具体生活与关系中的独特性，再写身份。结合关心方式、工作习惯、自己的目标、恐惧和边界，避免只靠“辛苦”“伟大”评价角色。

课件的“妈妈四层写法”提供一种从标签到细节、再到言行反差的示例。嘴硬心软适合用户希望呈现此类关系时使用，不能将所有父母写成相同人格，也不能仅凭责骂或付出就认定关系健康。具体案例与应用限制见 [课程参考](reference.md)。

课程关于节日、社会情绪与内容调性的建议是创作判断。没有用户提供的受众或投放背景时，沿用用户要求，不据此断言当前经济情况或所有观众的偏好。

## 输出方式

用用户的语言交付，篇幅和格式服从任务。常见形态：

- **人物设计：** 给出有因果的小传、当前欲望、裂缝、价值底线，以及能进入场景的记忆细节。
- **人物诊断：** 指出标签化发生的位置、缺失的行为证据或动机，并给出最少且有效的改法。
- **场景改写：** 直接提供可表演的正文；只在有帮助时附简短说明，指出关键动作与留白。
- **短片或拍摄脚本：** 用户要求时才增加时间段、动作、声音和镜头。15 秒练习和手机推拉摇移用法见 [短片参考](references/short-script.md)。

不默认输出人物生图提示词。用户需要从人物场景继续设计画面时，可在交付清晰的动作与关系后衔接构图任务。

## 交付前检查

确认重要选择能由经历、欲望或关系解释；至少有一个细节让人物特征可感；反差与留白有事实支撑；没有用身份标签替代人；没有新增未经允许的关系或剧情结果。若有反转，检查其线索与因果；若有时长，检查对白、动作和停顿是否能在该时长中完成。
